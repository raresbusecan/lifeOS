# Gate System

## Gates

### G0 Task Gate
Objective, parent, acceptance criteria and dependencies are coherent.

### G1 Context Gate
Relevant evidence is available and traceable.

### G2 Plan Gate
Plan, expected files and tests are coherent.

### G3 Scope Gate
Write permissions and protected areas are explicit.

### G4 Implementation Gate
Authorizes coding.

### G5 Validation Gate
Deterministic checks have run.

### G6 Review Gate
Independent review has passed.

### G7 Completion Gate
Definition of Done is satisfied.

### G8 Architecture Gate
Required for high-risk structural changes.
